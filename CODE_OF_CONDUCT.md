# Code of conduct

Everyone working on this project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give and take feedback gracefully, and keep discussion about the work. Harassment of any kind isn't accepted.

To report a problem, message the maintainers privately through GitHub ([@besaoct](https://github.com/besaoct)). Reports are kept confidential.
