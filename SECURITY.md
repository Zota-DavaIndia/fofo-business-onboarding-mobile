# Security

The app handles partner KYC documents, payment details and staff accounts, so security reports get priority.

## Supported versions

Only the latest release is supported. The in-app updater moves phones to it, and the backend can block older versions.

## Reporting a vulnerability

Don't open a public issue. Use GitHub's private reporting instead: the **Security** tab of this repository, then **Report a vulnerability**.

Include what you found, how to reproduce it and what it affects. You'll get a reply within three working days.
